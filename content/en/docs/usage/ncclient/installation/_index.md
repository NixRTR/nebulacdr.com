You can install ncclient in several ways:

| Method                                                              | Best for                                                                 |
|------------------------------------------------------------------------|---------------------------------------------------------------------------|
| [Docker](/docs/usage/ncclient/installation/docker/)                | The first lighthouse in a network, to also run Magic DNS               |
| [Binaries](/docs/usage/ncclient/installation/binaries/)             | Prebuilt CLI binaries from the Web UI or GitHub Releases                |
| [Windows Installer](/docs/usage/ncclient/installation/windows/)     | Windows: CLI, tray, and background service via one MSI                 |
| [NixOS](/docs/usage/ncclient/installation/nixos/)                   | NixOS hosts: a declarative `services.ncclient` module                  |
| [Pip (PyPI)](/docs/usage/ncclient/installation/pip/)                | Fallback when none of the above are suitable                           |

Choose one and follow the linked page. Then see [Usage](/docs/usage/ncclient/usage/) to enroll the device and start the daemon (or service).
