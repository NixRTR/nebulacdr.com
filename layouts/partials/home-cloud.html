What Nebula Commander does

Networks and nodes

Create networks, add nodes, allocate IPs and issue certificates. Lighthouses, relays, subnet routers and exit nodes included. Web UI docs

Groups and firewall rules

Put nodes in groups and decide who can reach what, with a diagram that shows the result.

Device clients

Apps for Windows and Linux, plus ncclient for servers and Docker. Enroll with a one-time code; configs and certificates stay up to date. Client docs

Self-host anywhere

Run it with Docker or the NixOS module on your own hardware, free. Installation docs
